# EXX TT/MPS Route Benchmark Design

## 目标

本测试回答一个限定而可判定的问题：对 ABACUS/LibRI EXX 中的三阶系数张量，TT/MPS 是否能在保持完整 EXX 矩阵与能量精度的同时，带来足以抵消分解开销的存储和运行时间收益。

首轮只使用已经通过 label-aware exact EXX gate 的小 Si 快照。只有小 Si 显示出明确收益，才继续 GaAs `k444`。本阶段不是生产实现，也不改变 LibRI 的张量格式或 EXX 数值路径。

## 已知尺度关系

记全超胞辅助基、AO 和占据秩分别为

\[
N_\mu,\qquad N_A,\qquad N_v.
\]

用户给出的典型关系是

\[
N_\mu\gtrsim 2N_A,\qquad N_v<N_A.
\]

三阶 TT 对按顺序排列的维度 \((n_1,n_2,n_3)\) 使用两个秩 \((r_1,r_2)\)，核心元素数为

\[
N_{\rm TT}=n_1r_1+r_1n_2r_2+r_2n_3.
\]

因此把最大的辅助基指标放在中间通常有较大风险，但不能仅凭维数排除；两个展开矩阵的实际奇异值谱才决定秩。本测试扫描每个张量的全部六种指标排列。

## 比较的三条路线

### 1. 静态系数路线 C

直接分解

\[
C_{\mu ij}.
\]

这是最难压缩的候选，但有一个重要优势：在固定几何和基组时，分解可跨 SCF EXX 更新重复使用。每次 EXX 只在相应 TT 核的物理指标上施加占据变换和库仑度量变换，不重新做 TT-SVD。

### 2. 占据投影路线 B

先计算

\[
B_{\mu iv}=\sum_j C_{\mu ij}O_{jv},\qquad D=OO^\dagger,
\]

再对 \(B\) 做 TT-SVD。它把一个 AO 指标精确降到占据秩，预期比原始 \(C\) 更容易压缩；但 \(O\) 随密度矩阵变化，TT-SVD 原则上需要在每次 EXX 更新重新执行。

### 3. 度量处理路线 X

对 Hermitian positive-semidefinite 的库仑矩阵

\[
V=U\Lambda U^\dagger
\]

删除满足当前白化规则的数值零模，并定义

\[
X_{xiv}=\sum_{\mu}(\sqrt{\Lambda}U^\dagger)_{x\mu}B_{\mu iv}.
\]

此时

\[
H_{is}=\sum_{xv}X_{xiv}X^*_{xsv}.
\]

这条路线的 Frobenius 截断直接作用在 EXX 的 Gram 因子上，也可能先减少有效辅助基维数。与 \(B\) 一样，如果从稠密 \(X\) 开始分解，TT-SVD 是每次 EXX 更新的代价。

## TT 运算与公平计时

测试不能把“压缩后重构稠密张量再调用原算法”当作加速。实现提供两个独立操作：

1. **物理指标变换**：矩阵只乘到包含目标物理指标的 TT 核上。例如在 \(C\) 的 \(j\) 核上施加 \(O\)，在 \(\mu\) 核上施加 \(\sqrt{\Lambda}U^\dagger\)。这不改变 TT 拓扑秩。
2. **TT Gram 收缩**：保留自由 AO 指标 \(i\)，其余两个物理指标在核心网络中直接与共轭网络收缩，得到 \(H_{is}\)，不形成稠密 \(C\)、\(B\) 或 \(X\)。

每条路线记录两类时间：

- `setup_seconds`：构造该路线稠密输入和执行 TT-SVD；
- `exx_seconds`：从已经存在的 TT 核得到 \(H\) 的物理指标变换和核心收缩时间。

路线 \(C\) 的稳态 EXX 比较不计可复用的 TT-SVD；路线 \(B\) 和 \(X\) 的稳态比较必须包含每轮重新构造张量和 TT-SVD。报告同时给出首轮总时间，避免隐藏预处理成本。

## 扫描空间

对 \(C(\mu,i,j)\)、\(B(\mu,i,v)\) 和 \(X(x,i,v)\) 分别扫描全部六种指标排列，并扫描

\[
\epsilon\in\{0,10^{-10},10^{-8},10^{-6},10^{-4},10^{-3}\}.
\]

`relative_tol=0` 是无截断数值基线，不预设 TT 秩为满秩。每个点记录：

- 原始维度、排列和两个 TT 秩；
- 两个切分的完整奇异值谱和丢弃权重；
- 稠密元素数、TT 核元素数及压缩比；
- TT 重构相对 Frobenius 误差；
- 直接核心收缩与稠密参考的 \(H\) 相对 Frobenius 误差；
- 相对于已有 LibRI 快照的 \(H\) 相对误差；
- 用原始 `D.post` 和 reference-cell blocks 得到的能量误差，单位 Ry/atom；
- setup、TT 核 EXX 收缩和稠密 occupied EXX 时间；
- 进程峰值内存。

计时先执行一次预热，再执行至少五次；报告中位数。若单次超过 30 秒，则允许只运行一次并明确标记样本数。

## 数值与实现校验

自动测试必须先验证以下恒等关系：

1. 六种排列在 `relative_tol=0` 下重构回规范指标顺序后与输入一致；
2. 对任意物理指标的 TT 核矩阵变换与稠密 `einsum` 一致；
3. TT Gram 核心收缩与稠密 \(XX^\dagger\) 一致，包括自由 AO 指标位于第 1、2、3 个位置的情况；
4. 从无截断 \(C\)-TT 依次施加 \(O\) 和 \(V^{1/2}\) 得到的 \(H\)，与 exact occupied EXX 一致；
5. 复数共轭方向、零 TT 秩、非法排列、维度不匹配和非有限输入必须 fail closed；
6. 扫描报告只包含有限 JSON 数值，不使用 `NaN` 或 `Infinity`。

测试遵循 RED→GREEN：生产接口出现前，聚焦测试必须因接口缺失失败；每组最小实现后重新运行聚焦测试和全部 `tools/exx_thc/tests`。

## 选择规则

报告保留完整精度—代价曲线，不用单一阈值替代数据。为了决定是否继续，定义一个保守可行窗口：

\[
\frac{\|H_{\rm TT}-H_{\rm exact}\|_F}{\|H_{\rm exact}\|_F}\le 10^{-8},
\qquad
|\Delta E|/N_{\rm atom}\le 10^{-8}\ {\rm Ry/atom}.
\]

在这个窗口内：

1. 先选择稳态 EXX 时间最短的点；
2. 若时间差小于 10%，选择 TT 核存储更小的点；
3. 若仍接近，优先选择静态 \(C\) 路线，因为它不需要每次 SCF 重新做 TT-SVD。

只有同时满足以下条件，才进入 GaAs `k444`：

- TT 核相对对应稠密三阶张量至少压缩 5 倍；
- 计入该路线实际需要的每轮分解后，EXX 路径至少加速 2 倍，或者静态 \(C\) 路线的核心收缩至少加速 2 倍且可复用 setup 被单独报告；
- 完整 \(H\) 和能量误差通过上述窗口。

如果没有点通过，结论就是当前全局三阶 TT/MPS 路线不值得继续；保留奇异值谱作为判断是否转向局域块压缩的证据，但本阶段不实现局域块 MPS。

## 运行边界

- 小 Si 使用现有已校验快照和 label-aware supercell oracle。
- 本地完成单元测试和小数据数值测试；服务器 66 用于权威小 Si 计时。
- GaAs 仍受现有 180 GB 内存门和 streamed-factor 设计门约束；小 Si 未通过时不提交 GaAs。
- 不修改 ABACUS/LibRI 生产 EXX，不宣称本诊断代码的 Python 时间等于最终 C++ 性能。Python 结果用于判断秩结构和排除没有压缩潜力的路线；若通过，再设计 C++/LibRI 原型。
